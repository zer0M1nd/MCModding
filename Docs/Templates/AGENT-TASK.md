# Agent 任务单

- 任务 ID / 协调者 / 执行 owner：待填写。
- 目标与完成条件：待填写。
- 当前需求依据与禁止事项：待填写。
- 基线：源码提交/工作树摘要、产品版本/哈希、固定依赖、配置。
- 写入资源：完整模块列表、Docs、测试实例及必要共享资源。
- 协调方式：优先可用工具；状态目录与工具版本待填写。没有工具才指定人工协调者。
- 认领结果：尚未申请；必须取得成功结果后才写入。
- 可读范围 / 可写范围：待填写。
- 接口约定：由谁维护 API、依赖快照、生成资源及集成产物。
- 测试范围与用户限制：待填写。
- 交付物与存放位置：待填写。
- 集成 owner / 合并顺序 / 跨模块验收：待填写。

执行者发现需扩大修改范围时，先申请全部新增资源并核对其他 owner，不能偷偷修改共享 API 或他人 build。阻塞时继续无冲突的只读工作，报告具体依赖；不抢锁。
